# Create an S3 connection description

A connection is scoped to one bucket, the same way
[`smb()`](https://oousmane.github.io/netfs/reference/smb.md) is scoped
to one share - paths are always relative to that bucket's own key
namespace. Support is provided by the s3fs package, used through its
underlying `S3FileSystem` object directly rather than its convenience
functions, which share one connection process-wide; a fresh client is
built locally for every call, the same way
[`ftp()`](https://oousmane.github.io/netfs/reference/ftp.md) does.
Construction doesn't contact AWS.

## Usage

``` r
s3(
  bucket,
  aws_access_key_id = NULL,
  aws_secret_access_key = NULL,
  region_name = NULL,
  endpoint = NULL,
  profile_name = NULL,
  ...
)
```

## Arguments

- bucket:

  Bucket name.

- aws_access_key_id:

  Optional access key id. Maps to the connection's stored username - see
  [`set_creds()`](https://oousmane.github.io/netfs/reference/set_creds.md).

- aws_secret_access_key:

  Optional secret access key. When supplied, it is written to the
  selected `keyring` credential store and is not retained in the
  connection.

- region_name:

  Optional AWS region.

- endpoint:

  Optional endpoint URL, for an S3-compatible service other than AWS
  (e.g. MinIO).

- profile_name:

  Optional named profile to read credentials from, instead of
  `aws_access_key_id`/`aws_secret_access_key`.

- ...:

  Backend options, passed through to `s3fs::S3FileSystem$new()` (for
  example `s3_force_path_style` for an S3-compatible service that needs
  it, or `anonymous = TRUE`).

## Value

A `netfs_s3` connection.
